## Server facts found (all verified with AD `dnsTombstoned` on the dnsNode objects)

| Fact | Evidence |
|---|---|
| Removing an A record by any path (Remove-DnsServerResourceRecord, WMI Remove-CimInstance, dnscmd /recorddelete) deletes the PTR that points at the record's name. A PTR pointing at another name survives. **Version-dependent:** the operator's older production servers leave the PTR behind (many orphans there); Microsoft documents no change for Server 2025, so the code re-reads the PTR instead of assuming. | R1–R4, field evidence |
| Set-DnsServerResourceRecord on an A record (TTL or address) deletes that PTR as well. | E1, E2, raw repro on srv02 |
| WMI `MicrosoftDNS_AType.Modify(TTL)` changes the TTL and leaves the PTR alone; `Modify(IPAddress)` deletes the PTR like the cmdlet. `MicrosoftDNS_PTRType.Modify(TTL)` works. | E3, E5 |
| No method keeps the aging timestamp: every change makes the record static. | 3c, E4 |
| The server accepts a CNAME that points at itself (no 9707). | 3i |
| An unreachable `-ComputerName` gives Category NotSpecified, ErrorId `WIN32 1722,<Cmdlet>` from the local provider, in 0.35 s. | measured 2026-10-11 |
| `Add-DnsServerPrimaryZone -NetworkId 10.251.0.0/24 -ReplicationScope Custom -DirectoryPartitionName DomainDnsZones.lab.example` shows as ReplicationScope Domain afterwards; the derived zone name equals Get-DnsReverseZoneName. | 1c–1d |
| Export-DnsServerZone writes non-ASCII owners as octal escapes of the UTF-8 bytes (`r\303\244ksm\303\266rg\303\245s`). | 2j |
| Silenced "not found" lookups (WIN32 9714) stay in the caller's -ErrorVariable, as §5.2b says. | 2g, 4h |

## Results per step

1. **New-DnsReverseZone**: -WhatIf (two WhatIf Results, nothing created), real run (CreateZone + SetZoneAging Success, aging 3 d / 10 d copied, replication warning), rerun AlreadyDone. PASS.
2. **New-DnsEntry**: -WhatIf; A+PTR; rerun AlreadyDone for both; CNAME; NodeIsCname and CnameCollision as Failed with the right ErrorIds; -NoPtr; NoReverseZone without creating the A; -CreateReverseZone chain (CreateZone, SetZoneAging, AddA, AddPtr); `räksmörgås` stored correctly live; 20-row CSV via -InputFile (40 Success); Update-DnsSnapshot exported six zones. PASS, except the snapshot search `räk*` (parser bug, fix in progress).
3. **Set-DnsEntry**: -TTL on a dynamic record Skipped with the exact text; with -IncludeDynamic the A was changed and became static; -Address, -Target, -PtrTarget (AddPtr when missing, SetPtrTarget otherwise), NotACname error, AlreadyDone. FAIL on PTR handling: the A change deleted the PTR, so SetTtl on the PTR reported "does not exist" and -Address wrote no RemovePtr (the server had already removed it). Fix in progress: TTL via WMI Modify, -Address order RemovePtr → SetAddress → AddPtr.
4. **Remove-DnsEntry**: pipeline from Get-DnsEntry (-WhatIf then real), -Identity with åäö, -InputFile with 20 names, a comment, a duplicate and an address with an orphan PTR (20 A + 21 PTR removed), WQL reference check (4 zones) with the exact Skipped text and -AllowReferenced warning, deserialized Entry via Export-/Import-Clixml, AlreadyDone, PatternNotAllowed. FAIL on -KeepPtr: the server removed the PTR with the A. Fix in progress: re-check after removal, Result + warning.
5. **Backup-DnsZone**: -WhatIf with a bad zone (Failed + ZoneNotFound error, three WhatIf, no folder), real run (three files + RESTORE.md), log schema with Name and Data on every line. PASS.
